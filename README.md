# 🪑 Natura Furniture — E-Commerce Website

A modern, fully responsive e-commerce web application designed for premium furniture and home decor, built with **WordPress**, **WooCommerce**, and **Elementor**.

## ✨ Key Features

- 🏠 **Custom Homepage Layout:** Includes hero banners, category grids, and customer review showcases.
- 🛍️ **WooCommerce Storefront:** Dynamic product listings with attribute variations (Color, Size, Material).
- 🔍 **Interactive Quick View:** View detailed product modal previews without leaving the catalog page.
- 🛒 **Shopping Cart & Checkout:** Smooth cart management with full checkout workflow.
- 💳 **Razorpay Integration:** Secure payment gateway integration supporting Cards, Netbanking, and Wallets.
- 📍 **Interactive Contact Page:** Embedded Google Maps and contact form for inquiries.
- 📱 **Fully Responsive:** Designed using Elementor and OceanWP theme for all device screen sizes.

---

## 🛠️ Tech Stack & Plugins

- **CMS Platform:** WordPress
- **E-Commerce Core:** WooCommerce
- **Page Builder & UI:** Elementor, OceanWP Theme
- **Payment Gateway:** Razorpay Payment Gateway
- **Web Technologies:** Custom CSS3, HTML5, JavaScript
